## Note on Automated Cloud Downloads

Due to YouTube's IP blocks on Google Cloud / datacenter IPs (returning `HTTP Error 403: Forbidden`), direct stream downloading via `yt-dlp` or standard HTTP requests requires authenticated cookies (`cookies.txt`).
Once a valid `cookies.txt` is provided or files are committed directly, the MP4 video files will be placed here under the designated ordered names.
