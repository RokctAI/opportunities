# EEIP Program: Microsoft South Africa EEIP

## Quick Stats
- **Multinational Company**: Microsoft
- **Administrator / Fund Manager**: Microsoft South Africa / Edge Growth
- **Application Status**: ONGOING
- **Target Audience**: Black-owned ICT SMMEs, digital start-ups, software developers
- **Focus Area**: Enterprise Development / Skills Development / R&D
- **Investment / Funding Type**: Grants / Equity / Tech Credits
- **Region / Territory**: South Africa
- **Website**: https://www.microsoft.com/en-za/

## Program Benefits
- **Financial Support**: Access to tech venture capital, software development grants, Azure cloud credits.
- **Non-Financial Support**: Deep technical enablement, business mentoring, market access, and software training.

## Eligibility Criteria
- 51% or more Black-owned ICT businesses, Qualifying Small Enterprises (QSEs) or Exempted Micro Enterprises (EMEs), focused on software development or digital technology.

## Program Description
Microsoft South Africa's R1.3 billion Equity Equivalent Investment Programme (EEIP) is designed to accelerate the development of South African SMMEs in the ICT sector, focusing on cloud computing, AI, and digital transformation.
