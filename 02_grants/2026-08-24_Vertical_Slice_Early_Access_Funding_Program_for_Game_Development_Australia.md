# Grant Opportunity: Vertical Slice / Early Access Funding Program for Game Development (Australia)

## Quick Stats
- **Organization**: Screen Territory (Northern Territory Government)
- **Deadline**: 2026-08-24
- **Funding Amount**: Up to 50,000
- **Focus Area**: Game Development, Micro-Prototype, Vertical Slice, Early Access

## Eligibility
- Open to Northern Territory based game developers, businesses, and sole traders registered in Australia.

## Description
Screen Territory is inviting applications for its Vertical Slice / Early Access funding program to support game developers in creating polished core gameplay experiences that demonstrate the quality and potential of a full game release. The program focuses on vertical slice development, early access game development, polished core gameplay, premium games, free-to-play games, live-ops development, entertainment games, interactive digital media, game production, and commercial game development.
