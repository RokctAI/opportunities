1. INTRODUCTION
The purpose of this document is to define the tender technical specification and evaluation criteria during
tender for establishing a contractor to demolish the old Matimba 450S WEBB guyed weather mast. This
project is needed for safety compliance, as not executing the project will result in the structure potentially
collapsing, posing a hazard to employees, nearby powerlines, and infrastructure.
2. SUPPORTING CLAUSES
2.1 SCOPE
This document covers the technical evaluation process and criteria to be used to appoint a suitable
contractor to demolish the old Matimba weather mast.
2.1.1 Purpose
The purpose of this tender technical evaluation strategy is to define the Mandatory Evaluation Criteria,
Qualitative Evaluation Criteria and TET member responsibilities for tender technical evaluation. The
technical evaluation strategy serves as basis for the tender technical evaluation process.

3.8 FORESEEN ACCEPTABLE / UNACCEPTABLE QUALIFICATIONS
3.8.1 Risks
Table 7: Acceptable Technical Risks
Risk Description
1. Weather-related delays due to high wind conditions
2. Use of rope access or crane-assisted methods where both are technically justified
3. Minor variations in demolition sequence without changing the top-down controlled dismantling approach
Table 8: Unacceptable Technical Risks
Risk Description
1. Any proposal involving uncontrolled collapse or free-fall demolition
2. Lack of engineering justification for stability during dismantling
3. Proceeding with demolition outside defined wind speed limits
4. Working at heights without a defined rescue plan
5. Use of uncertified lifting equipment or unqualified personnel
3.8.2 Exceptions / Conditions
Table 9: Acceptable Technical Exceptions / Conditions
Risk Description
1. Minor deviations from preferred demolition methods provided equivalent or better safety and engineering justification is submitted
2. Use of alternative equipment (e.g. different crane configuration) subject to updated load calculations and approval
Table 10: Unacceptable Technical Exceptions / Conditions
Risk Description
1. Requests to waive method statements
